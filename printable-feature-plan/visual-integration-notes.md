# 시각 자료 검수 기록

| 자산 | 검수 결과 | 반영 결정 |
|---|---|---|
| 서비스 확장 구조 그래프 | 한글 레이블, 현재 기반과 향후 기능 연결, 골드·블랙 브랜드 대비가 명확함 | 인쇄용 PDF에 삽입 |
| 개발 우선순위 로드맵 | 가로형 비율이 지나치게 넓어 A4 세로 페이지에 축소 삽입하면 텍스트가 작아질 위험이 있음 | 세로형 흐름으로 재렌더링 후 삽입 |

제공된 앱 화면은 기능 사례를 보여주는 용도로만 사용하며, 관리자 계정 이메일 등 개인 식별 정보가 포함된 화면은 인쇄용 기획서에서 제외한다.

## PDF 표본 검수

- 시각 자료를 추가한 PDF는 13페이지로 컴파일됐으며, 자동 검증은 통과했다.
- 기본 표본 페이지에서는 표·본문·머리말·페이지 번호의 잘림이 보이지 않았다.
- 기본 표본이 앱 화면과 그래프가 있는 페이지를 모두 포함하지 않았으므로, 시각 자료가 들어간 페이지를 별도로 렌더링해 최종 확인한다.

## 전체 페이지 검수

- 시각 자료 추가 후 PDF는 13페이지이며, 전체 페이지 렌더링을 완료했다.
- 서비스 확장 그래프와 세로형 개발 로드맵은 각각 10·12페이지에서 페이지 폭 안에 안정적으로 배치되고, 한글 레이블·화살표·캡션이 읽히는 것을 확인했다.
- 표·본문·머리말·페이지 번호는 모든 표본 페이지에서 페이지 경계를 넘지 않았다.
- 앱 화면 사례 그리드는 축소된 전체 시트에서 식별이 어려워, 해당 페이지를 개별 해상도로 확인한 뒤 최종 인쇄용 문서에 유지 여부를 결정한다.

## 앱 화면 렌더링 수정 및 재검수

- 최초 시도에서는 화면 그리드 안의 Typst 함수가 텍스트로 출력되는 문제가 있어, 콘텐츠 블록 안에서 실행되는 문법으로 수정했다.
- 수정 후 홈·등록하기 화면은 2페이지, 업체찾기·통합찾기 draft 화면은 6페이지에 실제 이미지로 렌더링됐다.
- 서비스 확장 구조 그래프는 11페이지에, 개발 우선순위 표는 12페이지에 A4 폭 안으로 배치됐다.
- 제목 번호의 중복도 제거했으며, 자동 검증은 다시 통과했다.

## 최종 인쇄 확인

- 홈·등록하기 화면은 2페이지에서 두 칸 구성으로 선명하게 표시되며, 캡션과 본문 사이의 간격도 유지된다.
- 현재 업체찾기와 통합찾기 draft 화면은 6페이지에서 구분되어 표시되고, draft가 출시 전 참고 화면이라는 문구가 함께 노출된다.
- 앱 화면, 서비스 확장 그래프, 개발 로드맵, 표와 본문은 A4 여백 안에 배치됐으며 페이지 밖 잘림이나 겹침이 확인되지 않았다.
